# Google Search guidance for Cryptita Plays

Researched 2026-10-05. Official Google sources only. This is guidance for a plan, not evidence that the deployed site passes these checks. The user reports that the domain is already verified; the property and its data have not been inspected. The site is a Philippine Web3 education and social impact initiative.

## Priority 0: eligibility and ownership

- Aim for cryptitaplays.com to become the leading organic result for the brand. Google explicitly says no technique automatically guarantees first place. Indexing itself is not guaranteed. [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)
- Reuse the existing verified property and confirm its type and access. A `cryptitaplays.com` Domain property covers protocols and subdomains and requires DNS verification. If it is already DNS-verified, retain the record; do not repeat setup. If only a URL-prefix property exists and domain-wide coverage is needed, add the Domain property using Google's exact DNS verification record. Add team users through Search Console rather than sharing account credentials. DNS changes can take days to propagate. A URL-prefix property with HTML verification is a fallback when DNS access is unavailable, but is narrower. [Ownership verification](https://support.google.com/webmasters/answer/9008080)
- Audit public pages for accessible content, crawlable links, meaningful HTTP statuses, and accidental indexing blocks. Google renders JavaScript, but server rendering or prerendering makes content available more directly. Use real `<a href>` navigation and proper not-found responses; an SPA returning 200 for every unknown path can cause soft-404 problems. [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)
- Choose a single HTTPS hostname. Align redirects, absolute canonical tags, sitemap entries, and internal links. Redirects and canonical tags are stronger canonical signals than sitemap inclusion; none overrides Google's final selection. Do not canonicalize every distinct content page to the homepage. [Canonical consolidation](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)

## Priority 1: discovery and branded identity

- Generate a sitemap containing preferred public URLs; use accurate modification dates rather than updating all dates on every build. Submit its URL in Search Console and reference it in robots.txt. Google ignores sitemap priority/changefreq values. [Build and submit a sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)
- Inspect the homepage and representative page types in Search Console: indexing eligibility, rendered output, selected canonical, and fetch status. After fixing meaningful issues, request indexing for a few important URLs. Requests are quota-limited, repeated requests do not accelerate crawling, and crawling can take days to weeks. [Recrawl requests](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl)
- Use the same concise brand name in homepage copy, prominent heading, title, and `og:site_name`. Add one homepage `WebSite` JSON-LD entity with `name: "Cryptita Plays"`, canonical `url`, and a genuine alternate name if used publicly. Google generates site names automatically. Validate syntax with Schema Markup Validator because Rich Results Test does not support site names. [Site names](https://developers.google.com/search/docs/appearance/site-names)
- Give each real page a descriptive title and clear primary heading. Keep the homepage title focused on the brand and actual offering. Avoid repeated boilerplate and keyword stuffing. Google may generate a different title link. [Title links](https://developers.google.com/search/docs/appearance/title-link)
- Write distinct, useful descriptions. Google primarily generates snippets from page content and may use a meta description when it better matches the query; an exact snippet is not guaranteed. [Snippets](https://developers.google.com/search/docs/appearance/snippet)
- Inference for this brand: make the homepage an authoritative destination explaining who Cryptita Plays is, its Philippine Web3 education and social impact work, what visitors can find, and which social channels are official. Link back to the domain from existing owned profiles, and pursue genuine relevant mentions. These are discoverability and identity actions, not a promise that social links directly boost rankings. [Search Essentials](https://developers.google.com/search/docs/essentials)

## Priority 2: useful content and eligible structured data

- For the initiative’s primary identity, use homepage `Organization` structured data with accurate name, URL, logo, description, and genuine official `sameAs` profiles. Google says this helps disambiguate organizations and can influence presentation; include only applicable facts, without inventing a legal designation, address, or registration details. This is a recommendation for this initiative, not proof of a guaranteed knowledge panel. [Organization guidance](https://developers.google.com/search/docs/appearance/structured-data/organization)
- Optionally, if a separate About page primarily describes an actual individual founder or contributor, `ProfilePage` with a `Person` mainEntity can be appropriate. Use public-facing name, real profile image, accurate description, and genuine `sameAs` profile URLs. An About Me page is a documented valid use case. Do not label an unrelated content hub as a profile page just to add markup. [ProfilePage guidance](https://developers.google.com/search/docs/appearance/structured-data/profile-page)
- If video search is a goal, provide individual watch pages where the video is the main content, with relevant explanatory copy and accessible thumbnails. Embedded third-party players can qualify; Google may index both the initiative's page and the platform page. A page listing many video cards is not automatically a watch page. [Video SEO](https://developers.google.com/search/docs/appearance/video)
- Add `VideoObject` only where it describes an actual visible video and accurate required fields are available. Validate supported structured data with Rich Results Test, then inspect deployed URLs. Markup supports eligibility rather than guaranteeing rich results. [Video structured data](https://developers.google.com/search/docs/appearance/structured-data/video)
- Improve real mobile usability and Core Web Vitals. Google's good thresholds are LCP <= 2.5 seconds, INP <= 200 milliseconds, and CLS <= 0.1. Use field data when available; technical performance alone does not guarantee rank. [Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals)

## Measurement and maintenance

- Record a baseline in Search Console using the branded queries `cryptita plays` and `cryptitaplays`, then segment by target country, device, and landing page. Track clicks, impressions, CTR, and average position. Average position describes the topmost site result, not a fixed universal ranking; results vary by time, place, device, and user history. [Performance report](https://support.google.com/webmasters/answer/7576553)
- Suggested operating cadence (planning judgment): weekly indexing/availability checks during launch; compare rolling 28-day branded performance after enough data exists; monthly content, links, and technical review. Investigate a nonindexed homepage before expanding content. Improve identity/content when indexed pages fail to satisfy the brand query. Avoid claiming that a single manual search proves the global rank.
- Define success as a sustained leading organic homepage result for the exact brand in agreed target markets, backed by query/page data and consistent spot checks. Keep indexing completion, site-name appearance, organic rank, and visitor conversions as separate outcomes.

## Inputs needed before implementation

1. Existing verified Search Console property type, report access, and account owner; DNS access only if verification maintenance or domain-wide setup is needed.
2. Main audience countries/languages and whether the brand query alone or broader Web3 education and social impact discovery is in scope.
3. Approved initiative description, official profile URLs, preferred brand spelling, and public founder/contributor bios if relevant.
4. Existing deployment/production domain setup and previous domains or migrations.
5. Content publishing capacity and whether individual video/article pages are desired.
6. Current baseline exports, if available, and intended visitor action (learn, join the community, participate, partner, contact).
